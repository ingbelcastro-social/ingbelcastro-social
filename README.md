# ingbelcastro-social

File pubblici per la pubblicazione automatica dei social di @ing.belcastro (Instagram, Facebook, YouTube) tramite Metricool.

- `_motore/`: motore grafico (caroselli e reel nello stile del canale).
- `media/AAAA-MM-GG/`: slide e video della settimana; Metricool li scarica da qui con i link raw.
